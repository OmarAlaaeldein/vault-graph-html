# How it works

1. Point `vault_graph.py` at a vault (or let it auto-detect).
2. It parses notes, resolves links, and injects them into `template.html`.
3. CI in this repo builds that HTML from `demo-vault/` and publishes it to GitHub Pages.

Start from [[Home]].
